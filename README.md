# 雄性意志 (Xiongzhi Will)

自然健身训练与营养定制系统。v0.1.0 初版发布。

**在线体验：** https://hf5060ti.github.io/xiongzhi-will/（GitHub Pages，手机/电脑直接打开，开源免费，无需登录）

**本站只提供健康自然的健身方式，不提供任何极端训练或药物方案；请遵守你所在国家/地区的法律法规。**

---

## 这是什么

一套基于 React + Vite + TypeScript 的纯前端健身应用。打开就能用，不需要登录、不需要后端、不需要数据库。所有数据存在你自己浏览器的 localStorage 里。

设计目标：**给自然训练者一个够专业、够详细、不绕弯的训练和营养工具。**

---

## 训练哲学

本站所有计算和计划都建立在几条自然训练原则上，也是本项目的"灵魂"：

1. **只服务自然训练者。** 不提供任何药物方案、不宣扬极端自律。自然状态下恢复能力有限，所有建议都围绕"练得对 + 睡得够 + 吃得稳"。
2. **组间休息按动作类型分档，不是一刀切 60 秒。**
   - 复合动作（卧推 / 深蹲 / 硬拉 / 推举 / 划船 / 引体等多关节大重量）：**3–5 分钟**。自然训练者磷酸原系统恢复、组间乳酸清除、中枢神经回稳都需要这个时间；短休息会让下一组在疲劳状态下开始，重量掉、动作变形，神经和肌肉都没受到该有的刺激。
   - 孤立动作（飞鸟 / 弯举 / 侧平举 / 下压等单关节小动作）：**2–3 分钟**，目标肌群局部恢复即可，太长反而冷身。
   - 判断标准只有一个：**下一组要在接近上一组的力量状态下再开始**，而不是按表到点就练。
3. **单次力量训练约 70 分钟封顶。** 超过这个时间，多余容量对自然训练者基本是"垃圾容量"——只影响恢复，不带来生长（长跑等耐力有氧除外）。
4. **睡眠 8–9 小时是训练的一部分。** 长期熬夜会升高皮质醇、压制睾酮，练得再狠也白搭。
5. **健身是生活的调味剂，不是被健身绑架。** 真正的力量不是肌肉多大、多能打，而是面对生活压力被击倒后能不能再站起来。

## 功能一览

| 模块 | 内容 |
|---|---|
| **目标设定** | 5 种训练目标：肌肥大 / 斗腕 / 大力士 / 综合体能 / 街头健身 |
| **饮食方案** | 4 种饮食：高碳低脂 / 生酮 / 碳循环 / 中碳 |
| **训练架构** | 三分化 / 四分化 / 五分化 / 二分化；正金字塔 / 倒金字塔 |
| **训练法则** | 练一休一 / 轻断食 14h–16h / 蛋白质分级 / 一天两练 |
| **动作百科** | 1541 个动作的演示动图 + 名师教学视频（谭成义），支持中英文搜索、部位/器械筛选 |
| **营养库** | 200+ 食物营养表（肉/水产/蛋奶/主食/豆类/蔬菜/水果/坚果/零食/家常菜熟食/少数民族食材） |
| **食物详情** | 每 100g 生重热量、蛋白质、脂肪、碳水、纤维、钠、维生素、矿物质、植物活性成分 |
| **今日饮食记录** | 选食物+克数加入记录，自动统计热量/蛋白质/脂肪/碳水，按餐次分组 |
| **一日三餐方案** | 按身体数据+目标+饮食方案生成每日目标与四餐搭配（每餐 2 套方案，精确到克） |
| **AI 热量估算** | 拍照/描述食物，自动估算每百克营养与总热量 |
| **营养素吸收率** | 脂溶性/水溶性维生素、血红素铁、草酸抑制钙等吸收提示 |
| **身体数据** | BMR（Mifflin / Harris-Benedict / Katch-McArdle / Cunningham）、TDEE、FFMI 上限、Casey Butt 模型、IPF 力量等级、1RM 换算 |
| **形体记录** | 二头/三头/胸型分类，附经典人物参考 |
| **AI 教练** | 训练建议、生病/恢复判断 |
| **冷兵器消耗** | 剑道/唐刀/苗刀/长枪等每小时热量估算 |

## 下载与部署

### 方式一：在线直接使用（推荐）

打开 **https://hf5060ti.github.io/xiongzhi-will/** 即可使用，手机、电脑都可以，无需登录。

### 方式二：下载源码自部署

1. 打开本仓库主页：https://github.com/hf5060ti/xiongzhi-will
2. 点右上角绿色 **Code** → **Download ZIP** 下载源码
3. 仓库自带 GitHub Actions：push 到 main 自动构建并部署到 GitHub Pages；`docs/` 目录为构建产物，`404.html` 已配置 SPA 路由回退
4. 也可以把 `dist/` 拖到 Netlify Drop，仓库自带 `vercel.json` 和 `netlify.toml` 路由回退配置

### 方式三：本地运行

```bash
git clone https://github.com/hf5060ti/xiongzhi-will.git
cd xiongzhi-will
npm install
npm run dev          # 开发：http://localhost:26666
npm run build        # 构建：产物在 dist/ 目录
```

构建完后，直接用浏览器打开 `dist/index.html` 即可使用。

### 缓存策略

- `index.html` → `Cache-Control: no-cache`
- `/assets/*`（带哈希文件名）→ `Cache-Control: public, max-age=31536000, immutable`

## 公式参考

### BMR 基础代谢（按优先级排序）

| 公式 | 适用 | 公式 |
|---|---|---|
| Katch-McArdle | 自然训练者首选 | BMR = 370 + 21.6 × LBM |
| Cunningham | 自然训练者备选 | BMR = 500 + 22 × LBM |
| Mifflin-St Jeor | 通用 | 男：10W + 6.25H − 5A + 5 |
| Harris-Benedict 修订 | 通用 | 男：88.362 + 13.397W + 4.799H − 5.677A |

LBM = 去脂体重 = W × (1 − 体脂率)

### TDEE 总消耗

TDEE = BMR × 活动系数

- 久坐 1.2 / 轻度 1.375 / 中度 1.55 / 高度 1.725 / 极高 1.9
- 增肌：TDEE + 300~500 kcal
- 减脂：TDEE − 300~500 kcal

### 蛋白质摄入（按训练年限）

| 级别 | 每公斤瘦体重 |
|---|---|
| 新手（0–1 年） | 1.5 g |
| 中级（1–3 年） | 1.8 g |
| 高级（3 年+ / 备赛） | 2.4–3.1 g |

### 肌肉上限（FFMI）

FFMI = 去脂体重(kg) / 身高(m)²

自然男性统计上限约 25，女性约 20–22。
